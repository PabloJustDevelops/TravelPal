# pnpm, accesibilidad y base de UI: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preparar una base reproducible para el rediseño de TravelPal y corregir los defectos de formularios verificados.

**Architecture:** Migrar instalaciones y runners conservando versiones, sin alterar los gates de deploy. Corregir semántica sobre los controles actuales; aislar el sistema en Storybook. La estética se migra después de elegir una propuesta visual.

**Tech Stack:** Next 16, React 19, Tailwind 4, pnpm 12.3.4, Jest, Playwright, axe, Tester Army, Storybook y posterior shadcn/Base UI.

**Spec:** `docs/design/2026-10-10-ui-qa-spec.md`

## Global Constraints

- pnpm 12.3.4 fijado en `packageManager`; Node 22.22.3 en CI.
- GitHub Actions sigue siendo la única vía de despliegue a Cloudflare.
- Conservar rutas, sesión y RLS.
- ADR-007 rige hasta aprobar una dirección que lo sustituya.

## Review Focus

- Instalación limpia sin paquetes transitivos expuestos por npm: frozen install y build Next/OpenNext.
- Comandos con argumentos: pnpm no necesita el separador `--` de npm; probar ambos runners.
- Formularios en oscuro: axe completo dentro del diálogo, incluidas categorías seleccionadas.
- Móvil y teclado: nombre del botón de alta, selección de radios y restauración de foco al cerrar.
- Datos privados: fixtures sintéticos en Storybook; los tests de formularios no guardan registros.
