# Estilo de Código

- TypeScript estricto cuando sea posible.
- Nombres descriptivos y consistentes.
- Evitar comentarios innecesarios; documentar decisiones relevantes.
- Mantener componentes pequeños y reutilizables.
- Usar utilidades compartidas en `src/lib/utils.ts`.
- Seguir ESLint/Prettier; ejecutar `pnpm run lint`.
