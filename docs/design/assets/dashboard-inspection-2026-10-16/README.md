# Capturas actuales de TravelPal

Fecha: 16 de octubre de 2026. Capturas de escritorio en 1440 × 1000 px, tomadas con el código del worktree `codex/auth-brand-a11y` y una cuenta sintética en un backend InsForge local aislado. Los datos de la cuenta están vacíos; no se insertaron viajes, tareas, gastos ni notas.

`overview.jpg` reúne una miniatura del viewport de cada sección. Para cada ruta se conserva `*-viewport.png` (primer viewport) y `.png` (página completa).

Secciones: dashboard, viajes, crear viaje, planificación, tareas, gastos y presupuestos, añadir gasto, notas, perfil y ajustes. Las rutas heredadas `/budget`, `/analytics` y `/alerts` redirigen a `/expenses` o `/dashboard`, por lo que no son secciones independientes en la navegación actual.
