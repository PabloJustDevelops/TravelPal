## Elección y alcance

Se usa `@sentry/browser` 10.76.2. El README y las declaraciones instaladas describen
un SDK para navegador con `init`/`captureException`; la documentación instalada de
Next 16.3.8 (`static-exports.md`) confirma los componentes cliente dentro del export.
`environment-variables.md` exige acceso estático a `process.env.NEXT_PUBLIC_*` para
sustitución en build. Se eligió browser frente a react porque ya existe un
ErrorBoundary propio; frente a nextjs, evita el acoplamiento de configuración de
servidor/edge y plugins que no necesita un Worker de assets. No se añadieron runtime
servidor, route handlers, túnel, `sentry.server.config.ts` ni `withSentryConfig`.

La rama mayor 10 mantiene `sendDefaultPii: false` (deprecado en sus tipos actuales;
v11 cambia el contrato de privacidad). El lockfile fija 10.76.2. El filtro propio
reconstruye el payload y elimina mensajes libres, query/fragmento, credenciales de
URL, cabeceras, cuerpos, contexto de viaje, breadcrumbs y usuario autenticado.
Solo conserva un ID anónimo aleatorio por carga y ubicaciones del stack. No se
activa replay, sesiones ni tracing automático; muestreo explícito configurable
0–0.05, defecto 0.01, con transacciones descartadas para no recoger datos de viaje.

SentryInit se evalúa antes del render cliente. ErrorBoundary y handlers globales
comparten captura/deduplicación por objeto; el fallback muestra la referencia del
evento. Release: `GITHUB_SHA` válido o SHA de Git; sin metadatos, ausente.
Detalles y referencias oficiales: [operación de Sentry](sentry.md).

Cuenta verificada por el propietario: `pabloorgs` / `travelpal`, región `de`,
plataforma `javascript-nextjs`. CI consume la variable de repositorio
`vars.NEXT_PUBLIC_SENTRY_DSN` durante el build; no un secret ni configuración runtime.
CSP y validación del DSN exigen únicamente
`https://o4511064837062656.ingest.de.sentry.io`, sin comodines.

Mapas: Next solo los genera en CI con token. El paso de CI los sube por release y
URL sin alterar los JS con hash, y los elimina antes del artefacto público incluso
si la subida falla. Sin token se omite la subida; un fallo con token bloquea CI.
